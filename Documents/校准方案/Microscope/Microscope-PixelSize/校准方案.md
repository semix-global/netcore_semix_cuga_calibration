# Microscope PixelSize 校准方案

## 1. 校准的目的

测量明场相机在每个倍镜下「1 个像素对应多少微米」，得到 X、Y 方向的实际像素尺寸（μm/pixel），用于图像像素坐标与物理尺寸的换算。

相机像元尺寸为 3.45μm/pixel（1 倍无放大），某倍镜理论值 = 3.45 ÷ 放大倍率。校准得出的实际值须与理论值核对（见 4.1），做校准是为了防止镜头畸变与装配误差导致偏离。

校准结果按倍镜记录，写入校准文件（镜头 + PixelSize）。

---

## 2. 校准方法

### 2.1 校准原理

以 CalChip 上已知周期的标准网格掩膜为基准（周期可选 10μm / 25μm / 50μm / 100μm），在明场下拍摄网格图像，由算法识别网格线并测量相邻网格线的像素间距：

$$
\text{PixelSize} = \frac{\text{标准网格周期(μm)}}{\text{相邻网格线像素间距均值}}
$$

- X、Y 方向分别计算，得到 (Width, Height) 两个像素尺寸
- 算法同时输出网格水平角度，若 |角度| > AngleThreshold（角度阈值）则判定失败（保证网格摆正、间距测量有效）

网格周期按「高倍配小周期、低倍配大周期」选择：高倍镜视场内大周期格子数量太少，参与统计的样本不足；低倍镜下小周期格子算法无法识别边界。

### 2.2 前置条件

- Microscope Focus 校准已完成
- Microscope CalChip 校准已完成（DSW Site 需使用其 DSWAlignmentDegree 与 DSW 明场基准位置）
- 明场相机可正常采图

---

## 3. 校准流程

校准流程分 3 步：**Select a lens → Select a location → Find Pixel Size**，之后执行 Verify。

### 3.1 Select a lens（选择镜头）

1. 选定 Cal Chip Site（Chuck / DSW / Undefined / Haze / Shiny Wafer）与待校准倍镜，软件自动切换至所选倍镜。
2. 软件移动平移台至该镜头记录的 FindPosition（网格区域明场坐标）。
3. Site 为 DSW 时，软件先将 Theta 旋转至 DSWAlignmentDegree（DSW 对准角度），再移动至 DSW 明场基准位置。

### 3.2 Select a location（选择位置）

1. 选定 Wafer Mask Type（晶圆掩膜类型，不参与算法）。
2. 对位平移台，使明场视场对准网格区域中心，能拍到尽量多且完整的网格。
3. 软件先做缓存有效性校验，再读取当前明场平移台坐标，记录为 FindPosition。

### 3.3 Find Pixel Size（采图计算）

1. 选定 Standard Mask Square Size（网格周期），设置 AngleThreshold(°)（须为非零值；推荐 0.00028°）。
2. 软件切换镜头并对位 FindPosition 一次，随后连续采图计算 10 次。
3. 每次测量：软件明场采图，算法计算 X/Y 像素尺寸与角度，保存原图与算法标注图各一张；|角度| > AngleThreshold 时判定失败。
4. 结果处理：
   - 10 次测量的 Width、Height 分别取算术平均，作为该镜头的 PixelSize 结果
   - 取与均值最接近的一次测量作为代表记录（保留其图像路径）
   - 保存校准结果，将该镜头标记为已校准

### 3.4 Verify（验证）

1. 对待验证的镜头记录设置 Threshold（验证阈值，Size）（须为非零值；推荐 (0.01, 0.01) μm，5X–150X 通用）。
2. Site 为 DSW 时，软件先将 Theta 旋转至 DSWAlignmentDegree，再对位该记录的 FindPosition。
3. 软件切换至该记录倍镜，以该镜头当前设置的网格周期单次采图计算，得到新 PixelSize（校准记录不保存周期，若与校准时不同，误差比较将失真）。
4. 软件计算 Error = 新测量值 − 旧校准值（Width、Height 分别相减）。
5. 判据：Error 的对角线长度 < Threshold 的对角线长度，满足则验证通过（标记验证通过）。

### 3.5 记录与文件输出

| 内容 | 说明 |
| ---- | ---- |
| PixelSize | 每倍镜一组 (Width, Height)，μm/pixel，10 次均值 |
| FindPosition | 该倍镜的网格区域明场坐标 |
| 图像 | 每次测量的原图与算法标注图 |
| 校准状态 | 已校准 / 已验证，按倍镜维护 |

## 4. 验收判定与异常处理

### 4.1 验收判据

| 项目 | 判据 |
| ---- | ---- |
| 单次测量 | 算法成功识别网格；\|网格角度\| ≤ AngleThreshold |
| 校准 | 10 次测量全部成功，结果为 10 次 X/Y 均值 |
| 验证 | 单次测量与旧校准值误差的对角线长度 < Threshold 对角线长度 |
| 结果合理性 | 实测值与理论值（3.45 ÷ 倍率）核对；明显偏离时排查网格周期误选、镜头与对焦，排除前不得放行 |

AngleThreshold 推荐 0.00028°，Threshold 推荐 (0.01, 0.01) μm（5X–150X 通用）。二者均为执行前人工设置的阈值，须为非零值，0 值时的失败行为见 4.2。推荐值能否进一步收紧待验证。

### 4.2 异常处理

| 异常 | 软件行为 |
| ---- | -------- |
| 算法在图像中找不到网格 | 该次测量失败 |
| 网格角度超限 | 该次测量失败；AngleThreshold 为 0 时任何非零角度均超限 |
| 采图失败 | 该次测量失败 |
| 验证误差超阈值 | 验证不通过；Threshold 为 0 时判据恒不成立 |
| 中途取消 | 流程中止，测量结果不保存，镜头保持原校准状态，报告标记 Failed |

---

## 5. 记录与周期

### 5.1 记录内容

- 每倍镜：PixelSize (Width, Height)、FindPosition、校准/验证状态
- 每次测量的原图与算法标注图
- HTML 校准/验证报告

### 5.2 复校时机

- 镜头更换、调校或相机更换后
- 光路变更后
- 图像测量尺寸出现系统性偏差时
- 验证失败且排除位置/对焦问题后

---

## 6. 当前状态与未来优化方向

- **当前状态**：50X 已完成一次完整「校准 + 验证」闭环（2026-07-02，Vela80，DSW Site，结果 0.069μm/pixel，与理论值一致）；2025-08 至 2026-04 的历史日志（B3、B4 两台设备，旧版本软件）中，5X、10X、10X-IR、50X、100X 均有「校准 + 验证」成功记录
- **优化方向**：
  - 网格周期与倍镜建立默认映射，避免人工误选
  - 网格周期写入校准记录，Verify 绑定读取校准时周期，避免校准后周期被修改导致误差比较失真
  - 网格周期、AngleThreshold、Threshold、实际角度写入日志，便于追溯
  - 修复 Verify 图像目录按被验证倍镜命名
  - 探索端到端移动验证：采图截取模板 → 按 PixelSize 换算平移台移动量（μm）→ 移动后再次采图 → 模板匹配计算实际像素位移，与预期像素位移对比，降低对网格位置的依赖

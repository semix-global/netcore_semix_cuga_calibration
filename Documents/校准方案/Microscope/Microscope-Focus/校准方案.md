# Microscope Focus 校准方案

## 1. 校准的目的

切换不同放大倍数物镜时，保证显微镜在 focus 范围内，尽量少的步进（理想情况一步即可）调整到最佳焦面，实现显微镜自动聚焦（AF）信号与最佳焦面一致。

- **校准对象**：各显微物镜（5X / 10X / 10X-IR / 50X / 100X；物镜配置以设备实际安装与界面可选为准，配置变更后须对新增倍镜补充校准）
- **校准参数**：最佳焦面 ECS 值；中继透镜（Aberration）电压（offset）

## 2. 校准方法与基准

### 2.1 校准方法

- 以图像清晰度为判据：在 ECS 区间内按固定间隔**遍历**采样，取已采样点中清晰度 Q 最高点对应的 ECS 作为最佳焦面
- 在最佳焦面处，对中继透镜（Aberration）电压做**二分法**迭代，使 AF error（Trace Buffer 平均值）收敛到阈值以内，记录该电压为 offset

### 2.2 前置条件

- ADS 的三项校准已完成：Pressure Gains、X Gains、Y Gains
- 显微镜硬件已连接，软件可正常下发 ECS 与中继透镜电压
- 五种物镜（5X / 10X / 10X-IR / 50X / 100X）已安装并可在界面选择
- 操作前已确认机械安全区间

### 2.3 校准准备条件

校准前需完成准备：将 DSW 晶圆放到 chuck 台上并真空吸附；关闭显微镜自动聚焦，打开工件台 Z 向（ECS）；降低 Z 轴到安全高度，移动 XY 轴使晶圆中心与光轴中心接近同轴。

## 3. 校准步骤与数据处理

### 3.1 校准步骤

1. **选择校准物镜**：选定待校准物镜（Select a lens），建议从最低倍数 **5X** 起步。
2. **选择校准点位**：移动晶圆，将合适的图案（网格区域、十字线区域、对比度高的地方）移动到明场中心，记录点位坐标（Select a location）。
3. **抓图计算清晰度（Q 算法）**：软件抓取成像图像，根据图像清晰度算法计算清晰度得分 **Q**。
4. **扫描寻峰（遍历）**：
   - 在预设的 ECS 区间 `[Min, Max]` 内，以固定间隔**遍历**采样，每步记录当前 ECS 值与对应的清晰度 Q
   - 采样过程中若连续 **30** 个点 Q 值不上升（下降或持平），则**提前终止**扫描
   - 采样结束后得到 ECS-Q 散点，**直接选取已采样点中 Q 值最高的点**对应的 ECS 值作为**最佳焦距**（不做抛物线拟合；最高点位于区间边界时不做失败判定，直接采用，此时应核对 ECS-Q 曲线是否覆盖真实峰值，必要时调整扫描区间复扫）
5. **Offset 归零（Set Voltage To AfError Zero，二分法）**：
   - 将 chuck 移动至最佳焦距
   - 对中继透镜（Aberration）电压做**二分法**迭代：在电压区间内取中点设置电压，读取 **AF error 的 Trace Buffer 平均值**
   - 根据 Trace Buffer 平均值的正负缩小电压区间（二分），重复迭代
   - 迭代结束条件（满足其一）：上一次误差已小于阈值且本次误差不再改善（取上一次中点电压）；同一中点电压重复出现 3 次（此时误差仍超阈值则判定失败）；达到 20 次迭代上限（判定失败）
   - 收敛阈值（可在运行前配置，须 ≥ 1）：按"归零后 AF error 足够接近最佳焦面、且二分迭代能够收敛"的原则选取——过小易归零失败，过大偏离最佳焦面；推荐值：B3 为 5X/10X/10X-IR **100**、50X **300**、100X **500**（其中 10X、10X-IR、100X 依据历史同物镜实测，尚无当前版本成功记录，复测确认前仅作执行参考），B4 五镜统一 **500**
   - 记录最终的中继透镜电压，即该倍镜的 **offset**
6. **切换物镜重复扫描**：软件不强制校准顺序，逐倍镜选定（Select a lens）后按步骤 3–5 重复执行，依次覆盖 10X → 50X → 100X → 10X-IR。

   > **遍历区间与间隔选择依据**：
   > - 低倍镜景深大 → 遍历区间大、间隔大
   > - 高倍镜景深小 → 遍历区间小、间隔小

7. **保存校准结果**：校准成功后，软件先设置该倍镜的标准 ECS 与中继透镜电压，再保存一条校准记录，该记录包含：物镜、点位坐标、最佳焦面 ECS 值、中继透镜电压（offset）、清晰度 Q、AF error（Trace Buffer 平均值）及校准/验证状态。

## 4. 验收判定与异常处理

### 4.1 校准结果验证

验证从读取校准文件开始，流程如下：

1. 选定待验证倍镜（SelectReviewItem），建议从 **5X** 开始。
2. 软件设置该倍镜标准 ECS 与中继透镜电压，开启明场，等待约 **5s** 稳定后抓取图像并计算复测清晰度。
3. 将复测清晰度与校准时记录的清晰度做差并取绝对值，`abs(NewQ - OldQ) < 阈值` 即通过，否则返回**校准失败**。阈值可在运行前配置，按"能拦截真实清晰度退化、又不因正常复测波动误报"的原则选取，推荐值：B3 **600**、B4 **150**。
4. 该倍镜验证通过后，依次对下一倍镜（**10X → 10X-IR → 50X → 100X**）重复上述验证与判定。
5. 单个倍镜验证通过后执行**齐焦（parfocal）检查**：若已验证（已校准且已验证）倍镜数 ≥ 2，比较**全部已校准倍镜**（含未验证）最佳焦面 ECS 值的极差，极差 ≤ 阈值即通过，否则将该倍镜置为未验证并返回**校准失败**。阈值可在运行前配置，按"各倍镜最佳焦面尽量齐焦"的原则选取，推荐值：B3 **150**、B4 **250**。极差使用全部已保存校准记录（含未验证记录）；旧记录可能引起额外失败，应核对参与集合并复校。
6. 全部通过后返回**校准验证成功**。

单个倍镜校准与验证均通过后，正常切换物镜时软件自动应用该倍镜保存的 ECS、标准 ECS 与中继透镜电压。

三项阈值的推荐值汇总如下，均依据 B3/B4 校准日志实测值分布统计得出：

| 阈值项目 | B3 推荐值 | B4 推荐值 |
|---|---|---|
| AF error 归零收敛阈值（3.1 步骤 5） | 5X / 10X / 10X-IR：**100**；50X：**300**；100X：**500** | 五镜统一：**500** |
| Verify 清晰度阈值 | **600** | **150** |
| 齐焦极差阈值 | **150** | **250** |

其中 B3 的 10X、10X-IR、100X 尚无当前版本成功记录，对应 AF error 推荐值复测确认前仅作执行参考；实际生效值以当次运行配置与日志记录为准。

### 4.2 异常处理

- **AF error 归零失败**（达到 20 次迭代上限，或中点电压重复 3 次后误差仍超阈值）时，返回 **Error**（或人工 **Canceled**），需重试：重新选择点位或调整扫描区间后重新扫描
- 扫描寻峰无失败判定：扫描结束（含提前终止）后，直接取已采样点中 Q 最高点作为最佳焦面
- 验证阶段误差或齐焦检查不达标 → 返回**校准失败**，需重新校准对应倍镜

## 5. 记录与周期

每次校准完成后，软件按倍镜生成 HTML 日志，并按 `data/<设备编号>/<日期>/` 归档。

- **校准日志**：记录所选倍镜、点位坐标、扫描区间与间隔、清晰度 Q 采样、最佳焦面 ECS、中继透镜电压及执行状态（OK / Failed / Canceled）
- **验证日志**：记录各倍镜复测清晰度、清晰度误差与阈值、齐焦偏移与阈值

复校时机：软硬件或光路发生变更、出现校准失败或生产质量反馈异常时应复校；日常按需执行校准，每执行一次校准即产生一组新日志。

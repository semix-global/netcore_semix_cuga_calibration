# Microscope Centricity 校准方案

## 1. 校准的目的

测量每个倍镜相对最高倍镜的成像中心偏移（Offset，μm），用于倍镜切换时自动补偿 XY 位移，使同一标记物在切换倍镜后仍保持在视场中心。

不同倍镜的成像中心（CMOS 中心与物镜光轴的对齐位置）存在装配偏差。切换倍镜后，原来对准的标记物会偏离视场中心，需手动移动 XY 才能重新看到它。Centricity 校准把这个补偿量测出来并保存，切换倍镜时自动应用。

校准结果按倍镜记录（CentricityPosition + Offset），其中 Offset 以最高倍镜为基准——最高倍镜自身的 Offset 记为原点 (0, 0)，其余倍镜的 Offset 是相对它的位移。

---

## 2. 校准方法

### 2.1 校准原理

在 CalChip 上选定一个带可识别图案（默认 DieCorner）的位置作为目标标记。对每个倍镜：

1. 用当前倍镜在标记处采图，截取视场中心一块作为模板（NCC 模板匹配）
2. 从记录位置出发，用模板匹配定位标记，得到该倍镜下标记居中的平移台坐标 CentricityPosition
3. 重复匹配 5 次取平均，得到该倍镜的 CentricityPosition
4. 计算相对最高倍镜的偏移：

$$
\text{Offset}_i = \text{CentricityPosition}_i - \text{CentricityPosition}_{\text{max}}
$$

最高倍镜作为参考，其 Offset 为 (0, 0)。

Verify 时模拟一次倍镜切换：先移到最高倍镜的 CentricityPosition，切换至待验证倍镜并施加其 Offset，再匹配模板得到标记实际位置，误差 = 实际位置 − 施加 Offset 后的期望位置，误差长度小于 Threshold 长度即通过。

### 2.2 前置条件

- Microscope CalChip 校准完成（所选 CalChip Site Model 已具备明场基准，用于在 CalChip 上移动与定位）
- Microscope PixelSize 校准完成（模板匹配的像素位移需经像素尺寸换算为微米；缺失或未验证时退回理论值 3.45 ÷ 倍率并记录警告）
- 明场成像清晰、可正常采图（依赖 Microscope Focus）
- 最高倍镜校准记录已存在（Verify 以最高倍镜 CentricityPosition 为基准，缺失会导致验证异常）

## 3. 校准步骤与数据处理

校准流程分两步：**Select a location（选位置）+ 逐个倍镜校准**，之后在 Review 界面执行 Verify。倍镜按倍率从高到低依次校准。

### 3.1 Select a location（选择位置）

1. **选择 Cal Chip Site 与 Template Type**：选定 Cal Chip Site（Chuck / DSW / Undefined / Haze / Shiny Wafer）与 Template Type（默认 NCC）。
2. **对准标记区域**：对位平移台，使视场对准标记区域。
3. **记录 FindPosition**：软件读取当前明场平移台坐标，记录为 FindPosition。

### 3.2 各倍镜校准（从高倍到低倍）

软件按倍率从高到低逐个处理，对每个倍镜执行以下步骤：

1. **切换倍镜**：软件切换至该倍镜。
2. **对准标记**：对位平移台，使标记对准视场中心附近。
3. **记录 FindPosition**：软件读取当前平移台坐标，记录为该倍镜 FindPosition。
4. **生成模板**：软件在当前视场中心截取并保存模板。
5. **缓存校验**：软件执行缓存有效性校验，失败则弹窗并中止。
6. **模板匹配 5 次**：每次从 FindPosition 采图、匹配模板定位标记，并换算得到该倍镜的 CentricityPosition。
7. **结果处理**：
   - 5 次 CentricityPosition 取算术平均作为该倍镜结果，取与均值最接近的一次作为代表记录；
   - Offset = 该倍镜 CentricityPosition − 最高倍镜 CentricityPosition（最高倍镜为 (0, 0)）。

### 3.3 Verify（验证）

1. **选择待验证记录与阈值**：选定待验证镜头记录，并设置 Threshold（验证阈值，Point）与 ConcentricThreshold（同心度阈值，μm）。
2. **移动到参考位置**：软件移动至最高倍镜的 CentricityPosition。
3. **切换倍镜并移动 Offset**：切换至该记录倍镜，并相对移动该记录的 Offset。
4. **模板匹配**：软件单次模板匹配，得到标记实际位置。
5. **验证判定**：Error = 实际位置 − 旧位置；**判据：Error 长度 < Threshold 长度 → 验证通过**（IsVerified = true）。
6. **同心度校验**：
   - 若已「校准且验证通过」的倍镜数 ≥ 2，软件计算各倍镜 Offset 长度的极差（最大 − 最小）；
   - |极差| ≤ ConcentricThreshold 才通过；否则 IsVerified 置回 false。

### 3.4 记录与文件输出

| 内容 | 说明 |
| ---- | ---- |
| CentricityPosition | 每倍镜一组 (X, Y)，该倍镜下标记居中的平移台坐标，5 次均值 |
| Offset | 每倍镜相对最高倍镜的位移 (X, Y)；最高倍镜为 (0, 0) |
| FindPosition | 该倍镜的标记区域明场坐标 |
| 图像 | 模板图与每次匹配的原图、标注图，按倍镜与日期存于 Images / Template 目录 |
| 校准状态 | IsCalibrated / IsVerified，按倍镜维护 |
| HTML 报告 | Calibrate / Verify 各一份 |

## 4. 验收判定与异常处理

### 4.1 验收判据

| 项目 | 判据 |
| ---- | ---- |
| 单次匹配 | 模板匹配成功（Score 达到该模板类型的匹配阈值） |
| 校准 | 5 次匹配全部成功，结果为 5 次 CentricityPosition 均值 |
| 验证 | Error 长度 < Threshold 长度 |
| 同心度 | 已验证倍镜 Offset 长度的极差 ≤ ConcentricThreshold（仅当 ≥ 2 个倍镜已验证） |
| 结果合理性 | Offset 数值量级合理（μm 级，且各倍镜 Offset 彼此接近） |

Threshold 与 ConcentricThreshold 为执行前人工设置的可配置参数。参考值：Verify Offset 0.1 μm，ConcentricThreshold 50 μm。

### 4.2 异常处理

| 异常 | 处理方式 |
| ---- | -------- |
| PixelSize 缺失或未验证 | 先完成 Microscope PixelSize 校准；否则退回理论值换算，误差可能失真 |
| 未校准最高倍镜（Verify） | 先校准最高倍镜，再验证其他倍镜 |
| 模板生成失败 | 检查视场内是否有可识别图案、模板尺寸与标记是否匹配 |
| 模板匹配失败（Score 低于阈值） | 检查 FindPosition 是否指向标记、图像是否清晰对焦、标记是否在视场内 |
| 缓存校验失败 | 按弹窗提示的错误信息排查参数设置 |
| 验证误差超阈值 | 重新执行校准；若反复超差，检查镜头/相机是否松动或更换过。Threshold 为 (0, 0) 时判据恒不成立，须先设置阈值 |
| 同心度超限 | 检查各倍镜 Offset 是否异常；ConcentricThreshold 为 0 时仅当各倍镜 Offset 长度完全相等才通过，须先设置阈值 |

## 5. 记录与周期

### 5.1 记录内容

- 每倍镜：CentricityPosition、Offset、FindPosition、校准/验证状态
- 模板图与每次匹配的原图、标注图
- HTML 校准/验证报告

### 5.2 复校时机

- 镜头、相机更换或调校后
- 光路变更后
- 倍镜切换后标记明显偏离视场中心时
- 验证失败且排除位置/对焦问题后

---

## 6. 当前状态与未来优化方向

- **当前状态**：已发布（release）并用于生产
- **优化方向**：
  - PixelSize 缺失时当前仅退回理论值换算，建议前置强校验并明确提示，避免误差失真
  - 模板匹配的 Score 阈值与 ConcentricThreshold 建立默认值或与倍镜关联

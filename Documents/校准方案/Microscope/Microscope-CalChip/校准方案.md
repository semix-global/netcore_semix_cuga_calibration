# Microscope CalChip 校准方案

## 1. 校准的目的

CalChip 是粘贴在 chuck 一角的一小片晶圆。它与 chuck 主体不处于同一水平面，存在约几百微米的高度差，导致 AF 伺服在 CalChip 上无法直接聚焦。

CalChip 校准的目的是：

- 记录 4 种晶圆模型（DSW、Undefined、Haze、ShinyWafer）的明场平移台坐标、ECS 值与清晰度
- 生成校准文件，供后续 CalChip 自动聚焦使用

---

## 2. 校准方法

### 2.1 CalChip 介绍

CalChip 是从晶圆上切下的一小片，用胶粘贴在 chuck 的一角上。它由四种晶圆组成，分别粘贴于 chuck 的四个角：左上 DSW、右上 Undefined、右下 Haze、左下 ShinyWafer。

### 2.2 校准原理

#### 2.2.1 高度差问题

- chuck 与 CalChip 各自内表面平整度误差不超过 ±2μm，但两者之间存在约几百微米的高度差
- 由于高度差的存在，在 CalChip 上使用 AF 伺服时，需要补偿该高度差才能正确聚焦

#### 2.2.2 校准方法（OM 曲线零点法）

AF 伺服通过 OM（光学）信号判断焦点：当 AF Error 为 0 时物镜正对焦，该位置即 OM 曲线的零点。ECS 是驱动 Z 轴（物镜与载台的间距）的伺服坐标，改变 ECS 即改变对焦高度。

做法：

1. 沿用 Focus 校准已确定的像差透镜位置（该位置已使 OM 零点与清晰度峰值重合）
2. AF 控制器匀速改变 ECS（等效于 Z 轴匀速移动），同步采集 OM 信号，得到「AF Error — ECS」曲线
3. 曲线与零轴（AF Error = 0）的交点即为该晶圆的焦点 ECS 值，同时记录该点的清晰度

本方法直接利用连续的 OM 信号，匀速扫描一次即可得到零点，速度快、精度高。目前采用 **低倍 5X + 高倍 50X 双倍镜模式**执行：ECS 扫描用 5X 镜，采图测清晰度用 50X 镜。

### 2.3 前置条件

- Microscope Focus 校准已完成（即已有各倍镜的像差透镜值和清晰度最大 ECS 值）

## 3. 校准步骤与数据处理

### 3.1 详细操作步骤

对 4 种晶圆模型（DSW、Undefined、Haze、ShinyWafer）依次执行以下步骤：

**① 定位晶圆区域**

每种晶圆用左上 + 右下两个点定位其在 chuck 角上的实际位置，记录两个点的平移台坐标；两点的中点即本次扫描的扫描位置。

**② ECS 扫描**

在扫描位置处，使用 **5X 镜**执行 ECS 匀速扫描（采图测清晰度时切换至 50X 镜）：

1. 以设定速度匀速扫描，扫描区间以当前平均 ECS 为中心向两侧各扩展一段可配置长度（对应扫描起止 ECS）。扫描速度与该扩展长度均为可配置参数（代码初始值分别为 500 ECS/s 与 250），执行时以界面/当次报告实际值为准
2. 产出 ECS—AF Error 曲线（Y: AF Error，X: ECS），从曲线零点得到该晶圆的 ECS 值与清晰度。曲线为离散采样点，零点按以下方式确定：在 AF Error 全局最小点与最大点之间的区间内，分别取最接近零轴的**非负**采样点与**负**采样点，以两者对应 ECS 的均值作为零点；区间内缺少非负或负采样点（即未跨零点）时校准失败。

**③ DSW 对齐（仅 DSW 晶圆）**

DSW 晶圆扫描完成后，额外执行对齐步骤，记录 DSW 对齐角度。首次对齐可能因匹配失败（匹配分数过低）而重试。

> 任一步骤失败 → 返回校准失败。

### 3.2 数据处理与输出

校准完成后生成校准文件，每种晶圆模型各记录明场平移台位置（平移台坐标）、ECS 值（曲线零点）、明场清晰度三个字段；DSW 额外记录对齐角度与对齐后的位置（仿射后位置）。

下游运行时，DSW 使用对齐后的位置（仿射后位置），其余三种晶圆使用各自的明场平移台位置，ECS 值与清晰度按校准值下发。

下发与保存顺序：每完成一个晶圆，即把该晶圆的位置与 ECS 值实时下发至 AF 服务；完整结果仅在全部晶圆（含最后的 ShinyWafer）完成后整体保存，验证通过后再次保存。中途失败或取消时，已下发部分的实时值可能残留，但完整结果未保存、不形成「已校准」状态。

校准过程产出各晶圆的 AF Error—ECS 扫描曲线与采图图像，随运行报告留存。

## 4. 验收判定与异常处理

### 4.1 校准结果验证

1. 读取校准文件
2. 设置角度为校准记录的 DSW 对齐角度，执行 DSW 对齐复验（复验会计算新的对齐角度，但不保存、不参与判定）
3. 依次对 4 种晶圆模型执行验证：下发该校准得到的 ECS 值后等待 3 秒，在对焦位置处用 50X 镜重新采图，得到新的清晰度；采图位置取自机台当前保存的位置值，ECS 取自校准文件
4. 验证判据：
   - **验证清晰度误差**：各晶圆验证与校准的清晰度差值（= 验证清晰度 − 校准清晰度）
   - **清晰度阈值**：可配置参数（代码初始值 1、约束 ≥1），为上述误差的上限，即各晶圆验证与校准的清晰度差值的绝对值须小于该阈值；执行时以界面/当次报告实际值为准
   - **验证 DSW 对齐角度**：DSW 晶圆对齐角度（该角度为校准时的对齐角度，即复验前的值，不参与验证判定）
5. 全部 4 种晶圆模型验证通过 → 返回校准验证成功
6. 任一晶圆验证不通过 → 返回校准失败

### 4.2 异常处理

| 异常 | 影响 | 排查与复校 |
|------|------|-----------|
| 倍镜切换失败或超时 | 校准或验证中断 | 检查倍镜切换机构，恢复正常后重试 |
| 扫描区间未跨零点 | 零点计算失败 | 调整扫描区间覆盖 AF Error 零点后重新校准 |
| 机台缺少 DSW 对齐结果 | 验证异常失败 | 确认机台已保存 DSW 对齐结果后重新验证 |
| DSW 对齐匹配失败 | 对齐失败 | 检查 DSW 晶圆定位，重新执行对齐（首次失败后重试可成功） |
| 清晰度误差超限 | 验证不通过 | 检查显微镜伺服 ECS 值与温漂，重新校准 |
| 中途取消 | 完整结果未保存，不形成「已校准」状态 | 不得放行，重新完成全部晶圆校准并验证通过 |

---

## 5. 记录与周期

- 复校时机：仪器硬件变更后需重新校准；出现 ECS 漂移、清晰度退化或验证误差超限时也应复校
- 每次校准与验证生成运行报告，存于按设备、日期归档的目录；报告含设备号、软件版本、时间、当次参数值、结果、失败或重试记录及验证误差
- 报告会被自动清理，需长期保存的应另行归档

---

## 6. 当前状态与未来优化方向

- **当前方案**：按本文档流程，在明场下用 OM 曲线零点法校准
- **已知局限**：
  - DSW 对齐角度不参与验证判定，无角度容差
  - CalChip 校准依赖 Focus 校准的准确性，Focus 对不准的问题同样会影响 CalChip 的精度

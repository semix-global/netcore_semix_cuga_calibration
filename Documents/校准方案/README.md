# 校准方案

本目录用于存放已经审核通过的校准方案。

## 分类规则

方案按 `Sources/Cuga-Calibration-Solution/ViewModels/` 的一级目录分类，并在分类目录下按校准项目单独存放。

方案新增或更新须关联上游 Issue，并从个人 fork 的独立分支向上游 `develop` 分支提交 Merge Request；不得直接修改上游 `develop`。

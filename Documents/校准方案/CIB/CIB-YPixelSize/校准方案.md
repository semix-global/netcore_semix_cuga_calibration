# CIB-YPixelSize Y 像素尺寸校准方案

## 1. 校准的目的

CIB（共焦成像盒）图像 Y 方向的像素尺寸（μm/pixel）由各路 PMT 的采样周期决定：同一产出信息下各路 PMT 之间存在个体差异，且不随载台扫描速度变化。Y 像素尺寸校准的目的是对每个产出信息逐路 PMT 实测 Y 方向像素尺寸，供主软件把 CIB 图像的 Y 像素坐标换算为物理坐标；与 X 像素尺寸共同构成 CIB 线同心度等后续校准的基础（线同心度校准中匹配偏移由像素换算为微米时，按路使用各自的 Y 像素尺寸）。

校准对象与输入输出：

- **校准对象**：每个产出信息下逐路 PMT 的 Y 像素尺寸（μm/pixel），独立保存
- **已知量**：暗场标准栅格图形的栅距（标准掩模尺寸配置，10 μm）
- **输出**：各路 PMT 的 Y 像素尺寸（验证通过后以复测值更新）

方法依据：暗场下标准栅格图形在 CIB 图像中呈现等间距条纹，条纹的像素间距即栅距对应的像素数，标准栅距（μm）除以相邻条纹像素间距的平均值即得 Y 像素尺寸。

---

## 2. 校准方法

### 2.1 校准原理

对每路 PMT 在其暗场位置采集一幅标准栅格图形图像，沿 Y 方向做灰度行投影得到投影曲线；对投影曲线（取反）做自适应多尺度峰检测，曲线的各极值位置即栅格条纹中心：

$$
\text{Y 像素尺寸} = \frac{\text{标准栅距（μm）}}{\text{相邻条纹像素间距的平均值（px）}}
$$

### 2.2 前置条件

- CIB 采图功能可用：激光、AOD 波形（Prescan / Chirp）配置正常
- 载台暗场坐标系可用；PMT 间距以运行时从光学系统读取的实际值为准
- 暗场对位参数（按产出信息）已就绪，或可在对位步骤中完成设置

---

## 3. 校准步骤与数据处理

校准流程依次为：准备与参数校验 → 对位 → 明场基准确定 → 逐路测量。验证（Verify）为独立流程。

### 3.1 准备与参数校验

- 选择并校验产出信息在软件支持的组合列表内；记录产出信息与 CalChip 模型类型（Chuck 模型 / DSW 模型）
- 校验并记录显微镜镜头、激光光路、CIB 通道号及光学配置、CIB 配置；各项均在支持列表内方可通过

### 3.2 对位

按明场或暗场方式执行载台对位（方式选择结果随校准项保存），记录对位结果。

### 3.3 明场基准确定

1. 校验当前镜头与配置一致
2. 记录当前载台机械位置为**明场基准位置**

### 3.4 逐路测量（主流程）

对机台配置的全部 PMT（按 PMT 编号升序）逐路执行：

#### ① 计算采集位置

读取机器坐标 Y 方向符号；第 i 路 PMT 的采集位置 = 明场基准位置 + Y 方向 × (该路 PMT 编号 − 主 PMT 编号) × PMT 间距

#### ② 采集暗场图像

移动载台至该路暗场位置，按当前光学与 CIB 配置采集一幅暗场图像。

#### ③ 计算 Y 像素尺寸

1. 对图像做 Y 方向灰度行投影
2. 对投影曲线（取反）做自适应多尺度峰检测，得到各条纹位置
3. 相邻条纹像素间距做中位数绝对偏差（MAD）剔野后取平均
4. Y 像素尺寸 = 标准栅距 ÷ 平均像素间距
5. 任一环节失败（如峰检测失败）则本步整体失败，记录错误图像

#### ④ 保存图像

保存原始图与算法标注图（标注条纹位置与投影曲线）。

#### ⑤ 结果汇总

全部 PMT 完成后逐路标记已校准；输出各路 Y 像素尺寸随 PMT 编号的汇总图。

### 3.5 Verify（验证）

1. 选择已校准项参与验证，须属于**同一产出信息**（不允许跨产出信息混合验证）
2. 重新执行对位后，对选中各路 PMT（按编号升序）按校准流程重新采集与计算，得到复测 Y 像素尺寸
3. 判据：|校准值 − 复测值| < 阈值（配方配置）
4. 判定结果：
   - 通过：以复测值更新该路 Y 像素尺寸并标记已验证
   - 不通过：保持原校准值，标记该路未验证并记录误差
5. 全部选中项均通过，验证整体才判定通过

## 4. 验收判定与异常处理

### 4.1 验收判据

| 项目 | 判据 |
| ---- | ---- |
| 峰检测 | 各路 PMT 投影曲线峰检测成功，剔野后间距数 ≥ 1 |
| Verify 采图 | 验证中选中各路 PMT 重新采图与峰检测均成功（任一路失败即验证终止） |
| Verify 数值 | 各路 \|校准值 − 复测值\| < 阈值（配方配置） |
| 整体判定 | 选中的全部 PMT 均通过，验证整体通过 |

### 4.2 异常处理

| 异常 | 流程状态与结果 | 处理方式 |
| ---- | -------------- | -------- |
| 峰检测失败 / 条纹异常 | 该路计算失败使整个校准步骤终止；本轮已测各路结果均不保存，须整批重新执行；验证阶段该路复测失败同样使验证终止，结果不保存 | 检查暗场图像质量（激光功率、CIB 配置、对位状态），确认标准栅格图形在采集位置视野内 |
| 复测超差 | 该路保持原校准值，标记未验证，误差随验证结果保存；验证整体判定不通过 | 检查该路 PMT 状态与采样配置；排查标准栅距配置与实物是否一致 |
| 采图失败 | 该路采图异常使整个校准或验证步骤终止，本轮结果不保存 | 检查载台到位、CIB 连接与通道配置 |
| 选中项未校准（验证） | 该路记为错误并跳过，验证整体判定不通过 | 先完成该路校准 |

## 5. 记录与周期

### 5.1 记录内容

- 各步骤参数：产出信息、镜头/光路信息、CIB 通道号及光学配置、CIB 配置、图像宽度、标准栅距、PMT 间距（内置默认值、运行时覆盖值与实际生效值）、验证阈值（内置默认值与配方实际生效值）
- 各路 PMT 的采集位置、暗场原始图、算法标注图与投影曲线图
- 校准结果：各路 Y 像素尺寸、校准与验证标志
- 校准与验证各生成一份 HTML 报告

### 5.2 复校时机

- 产出信息组合变更，或镜头、光路、CIB 硬件变更后
- 更换或调整 PMT、变更采样配置后
- CIB 线同心度校准前，确认相关路 Y 像素尺寸已校准且验证通过
- 下游使用 CIB 图像坐标出现系统性 Y 方向偏差时

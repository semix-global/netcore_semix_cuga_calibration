# CIB-XPixelSize X 像素尺寸校准方案

## 1. 校准的目的

CIB（共焦成像盒）沿 X 方向连续扫描成像时，图像像素与物理尺寸的换算比例（μm/pixel）由扫描速度与采样率决定，随**产出信息**不同而不同。X 像素尺寸校准的目的是对每个产出信息实测其 X 方向像素尺寸，供主软件把 CIB 图像的 X 像素坐标换算为物理坐标；与 Y 像素尺寸共同构成 CIB 线同心度等后续校准的基础。

校准对象与输入输出：

- **校准对象**：每个产出信息的 X 像素尺寸（μm/pixel）
- **已知量**：晶圆掩模图形沿 X 方向的曝光重复单元间距（设计值 = 单元间距 × 曝光单元数；单元间距与曝光单元数为配方按产品配置的参数，软件内置默认值分别为 5100 与 3，运行时以配方实际配置为准）
- **输出**：X 像素尺寸及其离散度（相邻重复单元像素间距的极差）

方法依据：产品图形沿 X 方向以固定间距重复。用模板匹配定位扫描长图中各重复单元的像素位置，相邻单元像素间距的平均值即一个重复单元间距所占的像素数，重复单元间距（μm）除以该像素数即得 X 像素尺寸。

---

## 2. 校准方法

### 2.1 校准原理

CIB 沿 X 方向从扫描起点连续扫描至终点，得到一条 16 位灰度的 RAW 长图。对长图滑窗做模板匹配，得到各重复单元的像素位置：

$$
\text{X 像素尺寸} = \frac{\text{重复单元间距（μm）}}{\text{相邻单元像素间距的平均值（px）}}
$$

模板匹配由外部算法库完成（输入图像与模板，输出匹配点、得分与角度，内部实现不可见）；匹配点筛选与 X 像素尺寸、离散度计算在本软件内完成。

### 2.2 前置条件

- Chuck Center And Theta 校准已完成（Chuck 模型下确定明场中心位置需要）
- CIB 采图功能可用：激光、AOD 波形（Prescan / Chirp）配置正常
- 晶圆在台，且图形周期、重复单元间距、晶圆半径等参数已按当前产品配置

## 3. 校准步骤与数据处理

校准流程依次为：准备与参数校验 → 对位 → 基准与模板生成 → 扫描测量。验证（Verify）为独立流程。

### 3.1 准备与参数校验

- 选择并校验产出信息在软件支持的组合列表内；记录产出信息与 CalChip 模型类型（Chuck 模型 / DSW 模型）
- 校验并记录显微镜镜头、激光光路、CIB 信息及光学配置、CIB 配置；各项均在支持列表内方可通过

### 3.2 对位

按明场或暗场方式执行载台对位（方式选择结果随校准项保存），记录对位结果。

### 3.3 基准与模板生成

1. 校验当前镜头与配置一致
2. 记录当前载台机械位置为**明场基准位置**
3. 在明场基准位置采集一幅 CIB 图像
4. 以该图像为底图人工框选特征图形生成匹配模板；模板随校准项保存，供校准与验证共用

### 3.4 扫描测量（主流程）

#### ① 生成扫描范围

1. 以明场基准位置为原点，按重复单元间距（单元间距 × 曝光单元数）在晶圆半径范围内生成网格，取过原点（Y=0）一行的全部重复单元，数量须大于 2
2. 扫描起点 = 首个单元中心 − 半个重复单元间距；扫描终点 = 末个单元中心 + 半个重复单元间距

#### ② 连续扫描采图

软件按当前光学与 CIB 配置从起点连续扫描至终点（正向、自动对焦开启），得到一条 RAW 长图；采集完成后载台返回明场基准位置。

#### ③ 滑窗模板匹配

- 窗口宽度 = 模板宽度 × 3，滑窗步进 = 模板宽度，对 RAW 长图逐窗做模板匹配；得分 ≥ 阈值判定匹配成功
- 匹配点 X 坐标 = 窗口起始像素 + 窗内匹配偏移

#### ④ 筛选匹配点

1. 同一 X 位置取最高得分
2. 对得分曲线做局部极大值检测，仅保留匹配成功点
3. 非极大值抑制（最小间距 = 模板宽度），去除相邻重复检出
4. 按得分降序取前 N 点（N = 重复单元数），再按 X 升序排列
5. 相邻匹配点 X 差值序列做中位数绝对偏差（MAD）剔野

#### ⑤ 计算结果

1. 匹配点数 ≥ 2 且剔野后差值数 ≥ 1，否则本步失败并记录全部匹配明细
2. X 像素尺寸 = 重复单元间距 ÷ 剔野后差值的平均值
3. X 离散度 = 剔野后差值的最大值 − 最小值（px）
4. 标记该产出信息已校准

### 3.5 Verify（验证）

1. 重新执行对位后重新扫描采图：网格与扫描终点沿用校准时的设置，扫描起点较校准前移半幅图宽，保证首个单元完整覆盖
2. 按已校准像素尺寸把重复单元间距换算为像素步进，以图像宽度为窗宽按预测位置逐窗切图并匹配；任一窗匹配失败则验证立即失败
3. 验证像素尺寸 = 重复单元间距 ÷ 验证差值平均值（验证差值不做剔野）
4. 判据：两项须同时满足，共用同一阈值
   - 验证差值极差 ≤ 阈值
   - 整片晶圆直径分别按验证像素尺寸与校准像素尺寸换算的像素数之差 ≤ 阈值
5. 判定结果：
   - 通过：以验证值更新 X 像素尺寸与离散度并标记已验证
   - 不通过：保持原校准值与离散度，标记该产出信息未验证

## 4. 验收判定与异常处理

### 4.1 验收判据

| 项目 | 判据 |
| ---- | ---- |
| 匹配数量 | 匹配点 ≥ 2，剔野后差值 ≥ 1 |
| 匹配质量 | 各窗匹配得分 ≥ 配置阈值，模板匹配成功 |
| Verify 采图 | 验证扫描中全部切窗匹配成功（任一失败即验证失败） |
| Verify 数值 | 验证差值极差 ≤ 阈值，且晶圆直径换算像素数之差 ≤ 阈值 |

### 4.2 异常处理

| 异常 | 流程状态与结果 | 处理方式 |
| ---- | -------------- | -------- |
| 匹配点数不足 | 本步失败并记录全部匹配明细；本次校准结果不保存，该产出信息沿用数据库中已有校准记录 | 检查模板框选质量、重复单元间距与晶圆半径配置是否与实物一致、CIB 图像质量 |
| 匹配得分普遍低于阈值 | 通常导致匹配点数不足，按「匹配点数不足」处理 | 重新框选模板，或检查激光功率、CIB 配置与对位状态 |
| Verify 切窗匹配失败 | 验证立即失败；本次验证结果与标志不保存，该产出信息保持原校准值与原验证标志 | 检查对位结果与图形状态；确认已校准像素尺寸无异常漂移 |
| Verify 数值超差 | 验证不通过；保持原校准值与离散度，标记未验证，误差随验证结果保存；验证整体判定不通过 | 核对重复单元间距设计值与实物；排查 X 像素尺寸漂移原因（扫描速度、采样率变更） |

## 5. 记录与周期

### 5.1 记录内容

- 各步骤参数：产出信息、镜头/光路/通道信息、光学与 CIB 配置、图像宽度、模板类型（NCC / Sharpe）与尺寸、匹配得分阈值、晶圆半径、重复单元间距（单元间距与曝光单元数的内置默认值与配方实际生效值）、验证阈值（内置默认值与配方实际生效值）
- 模板文件、扫描 RAW 图与逐窗匹配明细（起始像素、匹配点、得分、窗内偏移）及得分/差值曲线图
- 校准结果：X 像素尺寸、X 离散度、校准与验证标志
- 校准与验证各生成一份 HTML 报告

### 5.2 复校时机

- 产出信息组合变更，或镜头、光路、CIB 硬件变更后
- 扫描速度、采样率等影响像素尺寸的参数变更后
- CIB 线同心度校准前，确认本项已校准且验证通过
- 下游使用 CIB 图像坐标出现系统性 X 方向偏差时

# CIB-LineCentricity 线同心度校准方案

## 1. 校准的目的

主软件按 PMT 间距换算各路 PMT 的暗场采集位置；线中心实际位置偏离按间距推算的预期位置时，暗场图像将偏离预期位置。线同心度校准的目的是对每个产出信息的每路 PMT 实测暗场线中心位置，把线中心统一表达为**以晶圆明场中心为基准**的机器坐标位置，用于主软件的暗场定位与 CIB 采图位置换算。

校准对象与输入输出：

- **校准对象**：每个产出信息 × 每路 PMT 的暗场线中心位置（机器坐标，以晶圆明场中心为基准）
- **已知量**：PMT 间距（软件内置默认 320，加载时由光学系统实际值覆盖，以运行时读取值为准）、主 PMT 编号（固定）、Chuck Center And Theta 校准给出的晶圆明场中心、CIB X/Y 像素尺寸校准结果
- **输出**：各路线中心位置及相对主 PMT 的线中心偏移

方法依据：明场与暗场位置在载台机械坐标中存在固定偏移。校准时先确定明场基准位置，按 PMT 间距推算各路 PMT 的预期暗场位置并逐路采图匹配，以匹配得到的实际位置修正预期位置，得到各路线中心位置。



## 2. 校准方法

### 2.1 校准原理

对每路 PMT，在预期暗场位置采集 CIB 图像并与暗场模板匹配，得到线中心实际位置：

$$
\text{线中心位置} = \text{晶圆明场中心} + (\text{实测暗场位置} - \text{明场基准位置})
$$

其中匹配偏移先按 CIB X/Y 像素尺寸由像素换算为微米（X 用同产出信息的校准结果，Y 用同照明方式、同倍率、同 PMT 的校准结果），再按机器坐标方向符号修正。暗场模板匹配由外部算法库完成（输入图像与模板，输出匹配点、得分与角度，内部实现不可见），线中心位置换算在本软件内完成。各路相对主 PMT 的线中心偏移扣除 PMT 间距后，反映 CIB 各路线中心的排布残差。

### 2.2 前置条件

- Chuck Center And Theta 校准完成且有效（提供晶圆明场中心）
- 同产出信息的 CIB X 像素尺寸已校准且验证通过
- 各路 PMT 的 CIB Y 像素尺寸已校准且验证通过（按路使用）
- CIB 采图功能可用：激光、AOD 波形（Prescan / Chirp）配置正常

## 3. 校准步骤与数据处理

校准流程依次为：准备与参数校验 → 对位 → 基准与模板生成 → 逐路测量。验证（Verify）为独立流程。

### 3.1 准备与参数校验

- 选择并校验产出信息在软件支持的组合列表内；记录产出信息与 CalChip 模型类型（Chuck 模型 / DSW 模型）
- 校验并记录显微镜镜头、激光光路、CIB 信息及光学配置、CIB 配置；各项均在支持列表内方可通过

### 3.2 对位

按明场或暗场方式执行载台对位（方式选择结果随校准项保存），记录对位结果。

### 3.3 基准与模板生成

1. 校验当前镜头与配置一致，记录当前载台机械位置为**明场基准位置**
2. 采集显微镜明场图像，取图像中心区域（尺寸按模板尺寸配置）自动生成**明场模板**；生成失败则本步失败
3. 在明场基准位置采集一幅 CIB 图像，人工框选特征图形生成**暗场模板**；两个模板随校准项保存

### 3.4 逐路测量（主流程）

1. **前置校验**：
   - Chuck Center 校准有效
   - 同产出信息的 CIB X 像素尺寸有效
2. **生成采集位置**：读取机器坐标 Y 方向符号，取明场基准位置对应的暗场位置为基准暗场位置；第 i 路 PMT 的预期暗场位置 = 基准暗场位置 + Y 方向 × (该路 PMT 编号 − 主 PMT 编号) × PMT 间距
3. **逐路测量**（按 PMT 编号升序，对机台当前启用的全部 PMT 执行；启用集合随产率与生产配置变化）：
   - 移动载台至该路预期暗场位置，采集一幅暗场图像（图像宽度为配置项，默认 1000 px）
   - 与暗场模板匹配，实际位置 = 预期位置 + 匹配偏移（像素按 CIB X/Y 像素尺寸换算为微米，并按机器坐标方向符号修正）
   - 该路线中心位置 = 晶圆明场中心 + (实际位置 − 明场基准位置)
   - 单路匹配失败不中断流程：该路标记未校准并记录错误图像，其余路继续
4. **保存**：逐路保存线中心位置与匹配明细；路数大于 3 时，对各路相对主 PMT 的线中心偏移（扣除 PMT 间距）随 PMT 位置做一元线性拟合并输出拟合图（X/Y 方向各一条，斜率反映排布旋转分量），仅作诊断记录
5. **整体结果与路级结果**：存在匹配失败路时本步整体仍判定通过，各路结果以逐路校准标志为准

### 3.5 Verify（验证）

1. 选择已校准项参与验证，所选各项须属于**同一产出信息**（不允许跨产出信息混合验证）；主 PMT 编号的校准记录必须存在
2. 重新执行对位；再以明场模板在显微镜下定位当前明场位置（偏移按显微镜像素尺寸换算，该镜头像素尺寸未校准时按默认像素尺寸换算并告警）
3. **推算预期位置**：
   - 主 PMT 当前预期暗场位置 = 当前明场位置 + (校准时主 PMT 的暗场实测位置 − 明场基准位置)
   - 各路预期暗场位置 = 主 PMT 预期暗场位置 + Y 方向 × (该路 PMT 编号 − 主 PMT 编号) × PMT 间距 + 该路校准偏移（该路线中心相对主 PMT 线中心扣除间距后的残差，从已保存的全部校准记录中取值）
4. **逐路复测**：按预期位置采图、暗场模板匹配，得到实测位置；误差 = 实测位置 − 预期位置
5. 判据：|误差 X| < 阈值 X 且 |误差 Y| < 阈值 Y
6. 通过：标记已验证。不通过：保持原线中心，标记未验证并记录误差
7. 全部选中项通过，验证整体才判定通过；路数大于 3 时输出与校准相同的拟合诊断图

## 4. 验收判定与异常处理

### 4.1 验收判据

| 项目 | 判据 |
| ---- | ---- |
| 匹配质量 | 各路暗场模板匹配成功（得分 ≥ 配置阈值） |
| Verify 数值 | 各路 \|误差 X\| < 阈值 X 且 \|误差 Y\| < 阈值 Y（配方配置，X/Y 分设） |
| 路级结果 | 各路结果以逐路校准/验证标志为准，与整体状态分开读取；失败路编号与数量随记录保存 |
| 整体判定 | 选中的全部 PMT 均通过，验证整体通过 |

### 4.2 异常处理

| 异常 | 流程状态与结果 | 处理方式 |
| ---- | -------------- | -------- |
| 单路匹配失败（校准） | 该路标记未校准并记录错误图像，其余路继续；全部路测量完毕后统一保存；存在失败路时本步整体仍判定通过 | 检查该路 PMT 状态、激光功率与对位结果，补测该路 |
| 复测失败或选中项未校准（验证） | 复测失败路标记未验证并继续其余路；选中项存在未校准路时该路记为错误并跳过；验证整体判定不通过 | 检查该路 PMT 状态、激光功率与对位结果，补测该路 |
| 前置条件不满足（Chuck Center 无效、CIB X 像素尺寸无效） | 本步前置失败，校准/验证终止，无结果保存 | 先完成 Chuck Center And Theta 校准或对应产出信息的 X 像素尺寸校准与验证 |
| CIB Y 像素尺寸无效（按路） | 该路匹配前置失败，按单路失败处理 | 先完成该路 Y 像素尺寸校准与验证 |
| Verify 数值超差 | 该路保持原线中心，标记未验证，误差随验证结果保存；验证整体判定不通过 | 检查对位结果与晶圆明场中心；排查线中心是否漂移（温度、机械变更） |



## 5. 记录与周期

### 5.1 记录内容

- 各步骤参数：产出信息、镜头/光路/通道信息、光学与 CIB 配置、图像宽度、PMT 间距（内置默认值、运行时覆盖值与实际生效值）、模板类型与尺寸、匹配得分阈值、验证阈值（配方配置值与实际生效值）
- 明场/暗场模板文件、各路暗场图像与匹配结果图
- 各路匹配明细（匹配点、得分、角度、偏移）与验证误差
- 各路线中心偏移的线性拟合诊断图（X/Y 方向）
- 校准结果：各路线中心位置、校准与验证标志、失败路编号与数量
- 校准与验证各生成一份 HTML 报告

### 5.2 复校时机

- Chuck Center And Theta、CIB X/Y 像素尺寸校准更新后
- 产出信息组合变更，或镜头、光路、CIB 硬件变更后
- 主软件暗场定位出现系统性偏差，或各路暗场图像位置异常时

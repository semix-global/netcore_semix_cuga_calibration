## 回放方式

开发环境沿用 `FourierViewModel.UseSimulatorImage` 和 Fourier Mock 取图接口. 生产环境仍按真实相机校准的 Channel 3 ROI 裁图. 日志图片已经是通道图, 开发环境直接使用完整回放图片, 不再套用当前相机 ROI 二次裁剪, 也不要求先完成相机 ROI 校准.

光孔使用 `Channel3_X_LightHole_Step0.jpg` 和 `Channel3_Y_LightHole_Step0.jpg`. 用户将五个 ROI 的十字中心放在可见圆弧边缘, 不要放在直线挡杆边缘, 再拟合圆心和半径. 校准和复核都显示拟合圆.

挡杆图片根据实际输入角度和电机位置精确选择, Step0/Step1 文件对应下表位置的先后顺序, 但选择仍根据实际输入位置匹配. 因此互换两步位置时也会互换对应图片. 未记录的参数组合会报错, 不回退到随机图, 不插值或伪造图片.

## 校准约束

- Step0 的 X/Push ROI 只能左右移动, 用左右中心锚点修改宽度. Y ROI 只能上下移动, 用上下中心锚点修改高度.
- Step1 复制 Step0 的 ROI 尺寸, 只允许沿相同轴移动到同一挡杆, 不允许缩放. 两张图片必须同尺寸.
- 角度与两步电机位置保持绑定, Reset 仅清空结果. 执行期间禁用参数输入, 避免取图位置和计算使用的位置不一致.
- PixelSize = (Step1 电机位置 - Step0 电机位置) / (Step1 ROI 中心坐标 - Step0 ROI 中心坐标). X/Push 使用中心 X, Y 使用图片坐标中心 Y. 保留符号, 零位移及非有限结果不接受.
- 旧日志的正值像素/电机单位不能直接当作当前 PixelSize. 例如旧 X120 记录电机 -6 到 -8, 中心 X 为 1249.5 到 1370.5, 当前公式得到 -2/121. Y120 为 2 到 4, 中心 Y 为 1344.5 到 1215.5, 当前公式得到 -2/129.
